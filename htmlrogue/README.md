# 活页 / A page with a pulse

**网页的行为，就是游戏的行为。** 一个使用原生 HTML 元素构筑的静态 Roguelike Demo。

从一个攻击按钮开始，清理六层敌对页面；每次胜利保留一个新元素、节点变异或全局规则。元素直接存在于网页上，通过事件连接形成机器。没有手牌、抽牌、装备栏，也没有后端。

## 运行

安装 Node.js 20 或更新版本，在项目目录执行（无需安装依赖）：

```sh
node scripts/serve.mjs
```

打开 <http://localhost:4173>。如有 npm，也可使用 `npm start`。默认端口 4173，可通过环境变量 `PORT` 更改。

部署时直接将项目作为静态文件发布，例如 GitHub Pages。源码使用浏览器原生 ES Modules，**请通过 HTTP 访问，不要双击 index.html**。

## 怎么玩

1. 点击「攻击」。按钮变成 disabled，表示本回合已手动使用。
2. 点击「结束回合」，敌方反击，恢复按钮与 3 点操作额度。不必用完所有额度。
3. 清理第一页后，三选一获得开关、单选组或滑杆，同时自动接上第一条「变化 → 攻击」连接。
4. 进入下一页。调整新元素会自动攻击；按钮即使已经手动点击，仍能被连锁带动。
5. 每次清理后恢复 4 点完整度，保留一个永久改动。清理第六层即通关；完整度归零则失败。

所有控件支持浏览器原生键盘操作。刷新会开始新的一局；本版没有存档。

## 提炼与改进

原始构想全文保存在 [docs/original-concept.md](docs/original-concept.md)。Demo 保留三个核心：

- **页面就是资产**：奖励直接改变当前页面，成长可以从实际控件看见。
- **语义就是规则**：按钮触发、复选框持续、单选互斥、滑杆分配；使用真实控件与 disabled / checked 等状态。
- **事件就是构筑**：玩家选择起点、终点接线，形成可读的连锁，而不需要编程。

对原构想作了这些明确取舍：

| 问题 | Demo 的决定 | 原因 |
| --- | --- | --- |
| 无限点击没有取舍 | 每回合 3 操作点，每按钮手动一次 | 为防守、切换和连锁留出价值 |
| 滑杆每个像素都触发攻击 | input 仅预览，change 提交一次 | 不让采样率或拖动速度决定伤害 |
| 事件连锁出现得太晚 | 第一层必给支持节点并自动接线 | 尽早验证核心乐趣 |
| 来回改线能绕过回合成本 | 只能在回合首次操作前或层间改线 | 避免同一回合边点边重接 |
| 循环与分叉失控 | 广度优先队列、每节点每链一次、20 事件上限 | 防循环、重复汇聚和超大图 |
| 规则难以理解 | 提前显示敌方意图，保留事件回声 | 每次伤害、防护、连锁都能解释 |
| 内容数量掩盖玩法 | 6 层、4 类原生交互、10 种奖励定义 | 先完成短流程，再扩内容 |

敌对页面有递增反击、周期重击和每回合护盾等不同节奏。奖励包含攻击克隆、指定按钮强化、连接扩容，以及双重回响、缓存保护、连锁修复。首层教学固定，之后使用种子随机数抽取，过滤已有节点类型和唯一规则。

## 文件结构

```text
index.html                  语义结构与稳定挂载点
styles/
  base.css                  基础排版、原生控件、无障碍
  page.css                  页面布局与响应式断点
  components.css            节点、敌人、连接、奖励样式
src/
  app.js                    UI 动作编排，持有当前局状态
  content/
    nodes.js                节点定义、实例工厂、伤害计算
    enemies.js              六层敌对元素与行动意图
    rewards.js              奖励目录、资格筛选、种子随机
  engine/
    state.js                初始状态、全局常量、日志
    events.js               有界事件队列与元素效果
    game.js                 操作校验、回合、奖励、层推进、接线
  ui/
    dom.js                  安全的 DOM 构造工具
    node-view.js            原生控件渲染与用户输入适配
    render.js               页面各区域投影与焦点恢复
scripts/serve.mjs            零依赖本地静态服务器
tests/game.test.js           游戏规则与六层流程测试
docs/
  original-concept.md        完整保留的原始设计稿
  architecture.md            扩展指南与已知取舍
```

## 验证

```sh
node --test tests/game.test.js
```

也可执行 `npm test`。测试覆盖操作预算、控件状态、跨节点触发、护盾与超频、循环和事件预算、接线时机、奖励目标与去重、全局规则、胜负锁定，以及不跳过战斗的完整六层通关。

扩展前请阅读 [架构说明](docs/architecture.md)。

> The webpage is not where the game runs. The webpage is the game.
