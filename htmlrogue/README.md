# 活页 / A page with a pulse

**网页的行为，就是游戏的行为。** 原生 HTML 控件构成一台可改造的网页机器，探索没有最终关的敌对页面。

## 运行

需要 Node.js 20+，无需安装依赖：

```sh
node scripts/serve.mjs
```

打开 http://localhost:4173 。有 npm 时也可以用 `npm start`。浏览器原生 ES Modules 需要 HTTP 服务，不能直接双击 HTML。

## 双资源规则

- **算力**：当回合预算，回合结束清空；不再有额外的“操作点”限制。
- **数据**：本场跨回合保留，进入下一页清空并获得新补给，避免在安全 Boss 处无限囤积带入深层。
- **补给**：每回合基础总量固定 6，在 3/3、4/2、5/1（算力/数据）之间变化。下一次补给提前显示；资源随机流不受奖励抽取影响。
- **配置免费**：选择模式、调整滑杆、开关授权不付费，也不自动产生效果。主动提交按控件规则收费。
- **没有材料和商店**：清理后依然免费三选一，恢复 4 点完整度，提前展示下一页 Boss。

## 控件

初始拥有直达请求、折叠档案馆、临时防火墙。首层奖励固定提供后台锈蚀、洪流提交、缓存替身三选一。

| 控件 | 原生形式 | 初始规则 |
| --- | --- | --- |
| 直达请求 | button | 1 算力造成 3 伤害，可重复 |
| 临时防火墙 | button | 1 算力获得 4 护盾，可重复，敌方行动后护盾清空 |
| 折叠档案馆 | radio + 执行按钮 | 压缩 1 算力为 2 数据，或展开 2 数据为 1 算力；两模式共用每回合一次额度 |
| 后台锈蚀 | checkbox | 从下一回合开始，每回合付 1 算力 + 2 数据，施加 2 腐蚀；不足则暂停，之后自动重试 |
| 洪流提交 | range + 提交按钮 | 1 算力 + 所选数据，每点数据造成 2 伤害，初始单次最多 4 数据 |
| 缓存替身 | checkbox | 授权后，护盾不足时每 2 数据抵挡最多 1 伤害；不会提前扣费 |
| 清算坏账 | button | 1 算力，移除全部腐蚀并立即造成等量穿透伤害；获得锈蚀后才进入奖励池 |

**腐蚀**在敌方行动前造成等层数的穿透伤害，然后减 1。若杀死 Boss，不再反击。普通伤害先消耗敌方护盾。

**回合顺序**：腐蚀结算 → 判定击杀 → 敌方反击 → 玩家护盾 → 缓存替身按需扣数据 → 扣完整度 → 清空旧算力和护盾 → 新补给 → 背景进程付费运行。

持续控件在层间可以预设；开关配置跨页保留，资源和敌方状态不跨页保留。

## 成长与连接

局部升级按职责生效：请求/防火墙增强直接效果；档案馆提高压缩产量；锈蚀增加施加层数；洪流扩大单次容量；缓存提升每份数据防护量；清算追加即时伤害。选目标时展示升级后的完整规则。

全局奖励包含每回合额外护盾、每回合额外数据；重复奖励保留控件升级、连接扩容和完整度扩容，深层不会耗尽奖励池。

连接只接主动执行控件。**自动触发正常付费，并遵守一次转换等限制**；不足时跳过该节点，不继续传播该分支。免费配置和持续触发器不参与连接。每条链每节点最多一次，硬上限 20 节点。首次主动执行前或层间可以改接。

## 无尽 Boss

n 为页数，t 为本场回合，从 1 开始。所有 Boss 共用生命和基础攻击：

| 项目 | 公式 |
| --- | --- |
| 生命 H(n) | 6 + 8 × (n − 1) |
| 基础攻击 A(n) | 2 + floor((n − 1) / 2) |
| 成长量 G(n) | 1 + floor((n − 1) / 6) |
| 刷新护盾 S(n) | 1 + floor((n − 1) / 4) |

每页等概率抽取一个机制，不组合：成长反击为 A(n)+(t−1)×G(n)；刷新护盾在开战及每回合重置为 S(n)。下一层预告固定，不受奖励选择影响。

五个十层区域：失效链接街、缓存回廊、样式废墟、进程深井、文档尽头，随后循环并标记回访次数。独立名称词库只负责风味。

## 模块结构

```text
index.html                   页面语义与挂载点
styles/                      基础、布局、组件样式
src/
  app.js                     操作编排与焦点/滚动
  content/
    nodes.js                 控件元数据与实例
    rewards.js               奖励资格、抽取与目录
    enemies.js               Boss 公式、生成与行为
    enemy-names.js           独立命名词库
  engine/
    state.js                 单局状态
    resources.js             补给、费用、随机供给预告
    node-rules.js            费用/效果规格、配置校验与不可用原因
    effects.js               主动执行与伤害
    processes.js             后台任务、腐蚀、缓存抵挡
    events.js                有界付费事件队列
    progression.js           击杀奖励与升级
    connections.js           接线规则
    game.js                  回合阶段与公开操作
    log.js                   事件记录
  ui/
    dom.js                   DOM 工具
    node-view.js             原生控件
    resources-view.js        资源与补给预告
    rewards-view.js          奖励及升级目标
    connections-view.js      接线界面
    encounter-view.js        Boss、预告、公式
    render.js                区域协调
tests/                       资源、控件、敌人、无尽流程测试
scripts/serve.mjs             本地静态服务器
docs/architecture.md         时机与扩展说明
docs/original-concept.md     原始构想备份
```

## 验证与发布

```sh
node --test tests/*.test.js
```
